# Chlor

[![Made with Kotlin](https://img.shields.io/badge/Made%20with-Kotlin-blue.svg)](https://kotlinlang.org/)
[![Made with Love](https://img.shields.io/badge/Made%20with-Love-red.svg)](https://shields.io/)
[![Android 8.1](https://img.shields.io/badge/Android-8.1-brightgreen.svg?logo=android)](https://developer.android.com/about/versions/oreo)

**Chlor** is an aggressive GDI (Graphics Device Interface) variant specifically engineered for Android 8.1 (Oreo) and above. 

This GDI was developed using **Kotlin** within the **Android Studio** IDE.

## Overview

Chlor leverages low-level graphics manipulation techniques to provide high-performance rendering tailored for the Android Oreo environment. Designed with an aggressive approach to system interaction, it pushes the boundaries of standard GDI capabilities on modern Android architectures.

## Requirements

* **Android Version:** 8.1 (Oreo) or higher.

## Disclaimer

*Usage of this software is intended for testing purposes within environments. The author assumes no responsibility for system instability resulting from the use of aggressive GDI payloads.*
